## 캐릭터별 진영과 특징

| 캐릭터 | 진영 | 덱의 주제 |
|---|---|---|
| 조안 페레로 | 물 | 모험·보물 |
| 카탈리나 에란초 | 불 | 속공·돌파 |
| 오토 베인스 | 숲 | 전열·방어 |
| 에르네스트 폰 보어 | 숲 | 탐험·회복 |
| 피에트로 콘티 | 물 | 학술·주문 |
| 알 베자스 | 물 | 교역·마나 |
| 밀란다 베르테 | 불 | 약탈·은신 |
| 윤해강 | 숲 | 일기토·관통 |
| 마테오 레예스 | 불 | 추적·생포 |

덱의 주제는 카드 조합의 방향입니다. 항해 게임의 활동을 카드게임에서 그대로 조작한다는 뜻은 아닙니다. 예를 들어 조안은 순풍·신항로 발견, 카탈리나는 현측 포격·돌격 명령, 윤해강은 수군 궁수·총통 사격 같은 고유 카드를 모읍니다.

## 내 덱으로 여는 순서

1. 원하는 캐릭터로 **본편 또는 해당 외전**을 시작합니다.
2. 본편의 **이야기의 시작**, 외전의 **외전의 시작** 도전과제를 달성합니다. 새 게임을 고르기만 하는 것이 아니라 도전과제의 실제 조건을 채워야 합니다.
3. 카드 대전을 열어 새 카드 알림을 확인합니다.
4. **캐릭터 덱 → 덱으로 대전**을 누릅니다.

영웅 카드를 받으면 덱이 열립니다. 고유 카드 7장을 전부 모을 때까지 기다릴 필요는 없습니다. 아직 받지 못한 고유 카드 자리는 같은 진영의 시작 카드가 대신 채웁니다.

추가 카드는 그 캐릭터의 입항·교역·발견·해전·명성·이야기 진행 관련 도전과제로 받습니다. 외전은 본편과 조건이 다릅니다. 캐릭터 덱 화면의 **다음 카드**와 [도전과제 목록](/challenges/catalogue/)에서 현재 목표를 확인하세요. 조건을 달성하는 순서는 자유이며, 같은 보상을 다시 확인한다고 카드가 중복 지급되지는 않습니다.

## ‘도전’과 ‘덱으로 대전’은 다릅니다

| 단추 | 내가 쓰는 덱 | 상대 | 이용 조건 |
|---|---|---|---|
| **도전** | 플레이 화면에서 선택한 내 덱 | 해당 캐릭터의 완성 덱을 쓰는 컴퓨터 | 해당 캐릭터 덱을 아직 해금하지 않아도 도전 가능 |
| **덱으로 대전** | 내가 해금한 해당 캐릭터 덱 | 컴퓨터 상대 | 해당 캐릭터의 영웅 카드 필요 |

**도전에서 이긴다고 기본형 캐릭터 카드가 바로 나오는 것은 아닙니다.** 기본형 고유 카드는 본편·외전의 도전과제로 모읍니다. 캐릭터 도전 승리에는 일반 승리 보상 외에 금화 **40**이 추가됩니다.

## 친밀도와 단계 보상

캐릭터의 **도전** 또는 **덱으로 대전**을 정상적으로 마치면 해당 캐릭터의 친밀도가 오릅니다. 승리는 **3**, 패배는 **1**이 올라가며, 새 단계 보상은 한 번씩 받습니다.

| 필요한 친밀도 | 단계 보상 |
|---|---|
| 5 | 금화 100 |
| 15 | 해당 캐릭터 진영 팩 1개 |
| 30 | 금화 250 |
| 50 | 해당 캐릭터의 영웅·고유 카드 금빛 카드 7장 |

금빛 카드 보상과 기본형 카드의 도전과제 해금은 별도입니다. 덱이 잠겨 있다면 해당 캐릭터의 시작 도전과제를 먼저 확인하세요.

## 카드를 못 받았을 때

다른 주인공의 활동으로 해당 캐릭터 카드를 받을 수는 없습니다. 선택한 주인공, 게임 안의 도전과제 완료 표시, 카드 대전을 다시 열었는지를 차례로 확인하세요. 카드 모음 자체는 현재 기기에 저장되므로 기기를 바꾼 경우에는 [저장 범위](/card-game/#현재-제공-범위와-저장)도 확인해야 합니다.
