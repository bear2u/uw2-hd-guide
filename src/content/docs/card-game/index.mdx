시작 화면에서 **카드 대전**을 누르면 바로 들어갑니다. 본편이나 외전을 먼저 하지 않아도 **불·숲·물 시작 덱**으로 컴퓨터와 대전할 수 있습니다. 처음 카드 대전을 열면 카드게임용 금화 **300**을 받습니다.

## 처음이라면 이 순서로

1. [기본 덱 3종](/card-game/starter-decks/)에서 불·숲·물 중 하나를 고릅니다.
2. [첫 대전 따라하기](/card-game/tutorial/)를 보며 **플레이 → 솔로 → 시작**으로 한 판을 해 봅니다.
3. [카드 수집과 덱 편집](/card-game/collection/)에서 팩을 열고 가진 카드로 덱을 바꿉니다.
4. 좋아하는 주인공이 있다면 [캐릭터 덱 9종](/card-game/character-decks/)에서 카드 획득 조건을 확인합니다.

덱의 모든 카드를 그림과 함께 보고 싶다면 **[전체 덱 도감](/card-game/decks/)**을 여세요. 12개 덱의 영웅·20장 구성과 카드 121종의 비용·효과·수량을 정리했습니다.

## 어느 메뉴를 누르나요?

| 메뉴 | 할 수 있는 일 |
|---|---|
| **플레이 → 솔로** | 내 덱과 컴퓨터의 덱을 골라 대전합니다. 기본 규칙을 익히기 좋습니다. |
| **플레이 → 모험** | 준비된 단계별 대전을 진행합니다. |
| **플레이 → 캐릭터 덱** | 아홉 주인공의 덱과 도전하거나, 해금한 캐릭터 덱으로 대전합니다. |
| **컬렉션** | 카드 설명·보유 수량을 확인하고 덱을 편집합니다. |
| **팩** | 금화로 카드 팩을 사고, **팩 열기**에서 모은 팩을 엽니다. |

카드 메뉴 왼쪽 위의 전원 모양 단추를 누르면 대항해시대 시작 화면으로 돌아갑니다. 대전 중에는 왼쪽 위 메뉴의 **종료**로 카드 메뉴에 돌아온 뒤 나가세요.

## 본편과 카드게임은 어떻게 이어지나요?

본편·외전에서 **그 캐릭터의 도전과제**를 달성하면 해당 캐릭터 카드를 받습니다. 카드 대전을 다시 열어 새 카드 알림을 확인하세요. 일반 카드 팩과 시작 덱으로 즐기는 대전은 본편 진행과 관계없이 이용할 수 있습니다.

카드게임에서 쓰는 금화는 항해 중 가진 금화와 별도입니다. 카드 팩을 산다고 본편의 항해 자금이 줄어들지는 않습니다.

## 현재 제공 범위와 저장

현재는 **컴퓨터 상대 대전**을 제공합니다. 다른 이용자와의 온라인 대전은 아직 제공하지 않습니다.

카드 모음·덱·카드게임 금화는 **이 기기**에 저장됩니다. 카드게임의 계정 저장과 기기 간 이어하기는 아직 제공하지 않으므로, 본편 계정에 로그인했다고 카드 모음도 다른 기기로 옮겨지는 것은 아닙니다. 브라우저 데이터나 앱 데이터를 지우면 카드 기록을 잃을 수 있습니다.

이 안내의 그림은 현재 게임 화면입니다. 손패·선공 여부·상대 덱은 대전마다 달라질 수 있습니다. 작은 글씨는 그림 아래 **크게 보기**로 확인하세요.
