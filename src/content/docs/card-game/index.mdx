시작 화면에서 **카드 대전**을 누르면 바로 들어갑니다. 본편이나 외전을 먼저 하지 않아도 **전투·해적, 탐험·보급, 항해·교역 덱**으로 컴퓨터와 대전할 수 있습니다. 처음 카드 대전을 열면 카드게임용 금화 **300**을 받습니다.

## 단계별 튜토리얼 · 항해 훈련

처음이라면 **시작 화면 → 카드 대전 → 플레이 → 항해 훈련**을 여세요. **1단계 「첫 출항」**부터 시작하면 카드 내기·공격·턴 종료를 직접 해 보며 배울 수 있습니다. 배우고 싶은 단계를 골라 연습할 수도 있습니다.

<CardScreenshot name="training-stages" format="jpg" height={720} alt="첫 출항, 보급과 회복, 수비와 돌파, 선원 운용, 대형 함선의 다섯 훈련을 선택하는 화면" caption="항해 훈련에서 원하는 단계를 선택하세요. 각 단계는 정해진 덱과 상황으로 시작합니다." />

| 단계 | 배우는 내용 |
|---|---|
| **1. 첫 출항** | 지휘력, 카드 내기, 유닛과 상대 선장 공격, 턴 종료 |
| **2. 보급과 회복** | 도발로 선장 지키기, 독과 재생, 쓰러진 유닛 되돌리기 |
| **3. 수비와 돌파** | 도발 유닛으로 버티기, 관통, 체력이 가장 낮은 유닛 파괴 |
| **4. 선원 운용** | 은신한 상대, 도발·격노 선택, 아군 전체 강화 |
| **5. 대형 함선** | 전술 면역, 침묵, 장소 카드 활용 |

### 안내를 따라 진행하는 방법

1. 대전판 위의 **항해일지 안내 상자**를 읽습니다.
2. **다음** 단추가 보이면 눌러 설명을 넘깁니다.
3. 다음 단추가 없는 실습에서는 안내가 요구하는 행동을 합니다. 카드 내기나 공격은 카드를 길게 눌러 대상까지 끌어 놓습니다. 컴퓨터에서는 마우스로 드래그하세요.
4. 지정한 행동을 마치면 다음 안내로 넘어갑니다. 턴 종료 안내가 나오면 **턴 종료**를 누르세요.

<CardScreenshot name="training-first-step" format="jpg" height={720} alt="첫 출항 대전판 위에 다음 행동을 알려 주는 항해일지 튜토리얼 안내 상자" caption="설명은 다음 단추로, 실습은 안내에 나온 행동으로 진행합니다." />

각 단계를 **처음 이기면 카드게임 금화 250**을 받습니다. 1단계를 깨기 전에는 항해 훈련 단추에 **처음이라면 여기부터** 표시가 붙습니다.

훈련 뒤에는 **플레이 → 솔로**에서 직접 덱을 골라 대전해 보세요. 손패 교체, 화면 읽기, 공격과 보상은 [첫 대전 따라하기](/card-game/tutorial/)에서 그림과 함께 확인할 수 있습니다.

## 해도 탁자와 항해일지

카드 메뉴와 대전판을 해도 탁자로 꾸미고, 기본 카드 뒷면을 범선·나침반 문양으로 바꿨습니다.

- **카드 선택 화면:** 목재 탁자 위의 해도와 황동 항해 도구로 꾸밉니다. 대전 방식과 덱을 고르는 위치는 같습니다.
- **대전판과 카드 뒷면:** 어두운 해도 위에서 싸우며, 상대 손패의 뒷면과 쌓인 덱에는 범선·나침반 문양이 표시됩니다.
- **전투 기록:** 최근 행동의 작은 카드 그림과 설명 창을 항해일지 느낌으로 꾸밉니다. [전투 기록 확인하기](/card-game/tutorial/#전투-기록-확인하기)에서 실제 화면을 볼 수 있습니다.

배경과 장식이 바뀌어도 카드 비용·효과, 보유 카드와 덱 구성은 그대로입니다.

## 처음이라면 이 순서로

1. **플레이 → 항해 훈련**의 1단계 「첫 출항」을 해 봅니다. 화면의 안내를 따라 카드 내기·공격·턴 종료를 익힙니다.
2. [기본 덱 3종](/card-game/starter-decks/)에서 전투·해적 / 탐험·보급 / 항해·교역 중 하나를 고릅니다.
3. [첫 대전 따라하기](/card-game/tutorial/)를 보며 **플레이 → 솔로 → 시작**으로 한 판을 해 봅니다.
4. [카드 수집과 덱 편집](/card-game/collection/)에서 팩을 열고 가진 카드로 덱을 바꿉니다.
5. 좋아하는 주인공이 있다면 [캐릭터 덱 9종](/card-game/character-decks/)에서 카드 획득 조건을 확인합니다.

덱의 모든 카드를 그림과 함께 보고 싶다면 [전체 덱 도감](/card-game/decks/)을 여세요. 12개 덱의 선장·20장 구성과 카드 121종의 비용·효과·수량을 정리했습니다.

## 어느 메뉴를 누르나요?

| 메뉴 | 할 수 있는 일 |
|---|---|
| **플레이 → 솔로** | 내 덱과 컴퓨터의 덱을 골라 대전합니다. 기본 규칙을 익히기 좋습니다. |
| **플레이 → 항해 훈련** | 안내 상자를 따라 규칙을 익히는 5단계 튜토리얼입니다. |
| **플레이 → 캐릭터 덱** | 아홉 주인공의 덱과 도전하거나, 해금한 캐릭터 덱으로 대전합니다. |
| **컬렉션** | 카드 설명·보유 수량을 확인하고 덱을 편집합니다. |
| **팩** | 금화로 카드 팩을 사고, **팩 열기**에서 모은 팩을 엽니다. |

카드 메뉴 왼쪽 위의 전원 모양 단추를 누르면 대항해시대 시작 화면으로 돌아갑니다. 대전 중에는 왼쪽 위 메뉴의 **종료**로 카드 메뉴에 돌아온 뒤 나가세요.

## 본편과 카드게임은 어떻게 이어지나요?

본편·외전에서 **그 캐릭터의 도전과제**를 달성하면 해당 캐릭터 카드를 받습니다. 카드 대전을 다시 열어 새 카드 알림을 확인하세요. 일반 카드 팩과 시작 덱으로 즐기는 대전은 본편 진행과 관계없이 이용할 수 있습니다.

카드게임에서 쓰는 금화는 항해 중 가진 금화와 별도입니다. 카드 팩을 산다고 본편의 항해 자금이 줄어들지는 않습니다.

## 현재 제공 범위와 저장

현재는 **컴퓨터 상대 대전**을 제공합니다. 다른 이용자와의 온라인 대전은 아직 제공하지 않습니다.

카드 모음·덱·카드게임 금화는 **이 기기**에 저장됩니다. 카드게임의 계정 저장과 기기 간 이어하기는 아직 제공하지 않으므로, 본편 계정에 로그인했다고 카드 모음도 다른 기기로 옮겨지는 것은 아닙니다. 브라우저 데이터나 앱 데이터를 지우면 카드 기록을 잃을 수 있습니다.

손패·선공 여부·상대 덱은 대전마다 달라질 수 있습니다. 작은 글씨는 그림 아래 **크게 보기**로 확인하세요.
