카드 수집은 **대전으로 금화 모으기 → 팩 구입·개봉 → 컬렉션에서 확인 → 덱에 넣기**로 이어집니다. 주인공 고유 카드는 별도로 [본편·외전 도전과제](/card-game/character-decks/)에서 모읍니다.

## 컬렉션에서 카드 찾기

상단의 **컬렉션**을 누릅니다. 왼쪽에서 진영, 보유·미보유, 카드 종류와 등급을 좁혀 볼 수 있고 아래 검색칸도 사용할 수 있습니다. 가운데 카드를 누르면 설명을 크게 읽을 수 있습니다.

<CardScreenshot name="collection" alt="왼쪽 카드 필터, 가운데 카드 모음, 오른쪽 덱 목록이 있는 컬렉션 화면" caption="왼쪽은 찾기, 가운데는 카드, 오른쪽은 덱입니다. 그림이 흐리게 보이는 미보유 카드도 구분해 확인하세요." eager />

첫 방문 때 **시작 덱 하나를 선택하세요** 창이 나오면 덱을 골라 계속 진행합니다. 세 시작 덱의 비교는 [기본 덱 안내](/card-game/starter-decks/)에서 볼 수 있습니다.

## 팩 구입과 개봉

1. 상단 **팩**을 누릅니다.
2. 원하는 팩 그림을 눌러 설명과 비용을 확인합니다.
3. 수량을 확인하고 **구매**를 누릅니다.
4. 팩 목록으로 돌아와 **팩 열기**를 누르고 보유한 팩을 엽니다.
5. 컬렉션으로 돌아와 새로 얻은 카드를 확인합니다.

<CardScreenshot name="pack-buy" alt="일반 팩 한 개의 수량 1, 비용 100과 구매 단추가 표시된 화면" caption="구매 전에 수량과 총비용을 확인하세요. 일반 팩 한 개는 금화 100이며 카드 5장이 들어 있습니다." />

| 팩 | 가격 | 카드 수 |
|---|---|---|
| 일반 팩 | 금화 100 | 5장 |
| 정예 팩 | 금화 250 | 5장 |
| 불·숲·물 진영 팩 | 각각 금화 250 | 각각 5장 |

처음 받은 금화 300으로 일반 팩 세 개를 살 수도 있고, 정예 또는 진영 팩 한 개를 살 수도 있습니다. 원하는 카드가 반드시 나오는 것은 아닙니다. 카드게임 금화는 일반 대전 승리 시 **60**, 패배 시 **20**을 받으며, 캐릭터 대전의 친밀도 보상으로도 모을 수 있습니다.

## 가진 카드로 덱 바꾸기

**컬렉션 오른쪽의 덱 이름**을 누르면 편집 화면이 됩니다.

<CardScreenshot name="deck-editor" alt="숲 시작 덱의 카드 목록과 저장 단추, 20/20장 표시가 있는 덱 편집 화면" caption="오른쪽이 현재 덱 구성입니다. 교체를 마친 뒤 장수 표시와 저장 단추를 확인하세요." />

1. 오른쪽 목록에서 빼고 싶은 카드를 누릅니다.
2. 가운데 카드 모음에서 넣고 싶은 **보유 카드**를 누릅니다.
3. 장수 표시를 **20/20**에 맞춥니다. 같은 종류의 카드는 최대 **2장**까지 넣습니다.
4. 아래 **저장**을 누르고, 플레이 화면에서 사용할 덱을 다시 확인합니다.

편집 중 가운데 카드를 누르면 덱에 추가하는 동작이 됩니다. 설명만 크게 보고 싶다면 컴퓨터에서는 카드 위에서 오른쪽 마우스 버튼을 쓰거나 편집을 나와 카드를 선택하세요.

## 처음 편집할 때의 요령

- 높은 비용의 카드만 모으지 말고 첫 몇 턴에 낼 카드도 남깁니다.
- 캐릭터와 주문을 함께 넣어, 손패에 주문만 남는 상황을 줄입니다.
- 실제로 쓰기 어려웠던 카드 한두 장을 바꾼 뒤 같은 덱으로 다시 대전해 봅니다.
- 새 카드의 비용뿐 아니라 대상과 발동 조건도 읽습니다.

카드가 추가되지 않으면 보유 수량과 같은 카드의 덱 내 장수를 먼저 확인하세요. 새 캐릭터 덱을 여는 방법은 [캐릭터 덱 9종](/card-game/character-decks/), 실제 카드 사용 방법은 [첫 대전 따라하기](/card-game/tutorial/)로 이어집니다.
