:::note[제공 상태]
외전은 **모바일과 웹에서 플레이할 수 있습니다**. 자세한 제공 상태는 [제공 현황](/help/changelog/)에서 확인하세요.
:::

제노바의 소녀 **밀란다 베르테**가 모험가 피에트로를 쫓아 탐험가가 되는 이야기와, 해적 제독 **살바도르**의 이야기가 하나로 이어집니다. 본편 여섯 주인공과는 별도로 시작하는 항해입니다.

## 시작과 이어하기

1. 타이틀에서 **새 게임**을 누릅니다.
2. 주인공 고르기 화면의 **외전 · 밀란다** 카드를 고릅니다.
3. **외전 시작**을 누르면 아침 제노바에서 도입 이야기가 열립니다. 이름을 따로 정하지 않으며 능력치는 이야기 속에서 정해집니다.
4. 다시 이어 할 때는 타이틀의 **불러오기**에서 **외전** 표시가 붙은 저장을 고릅니다.

밀란다편을 마치면 살바도르편으로 이어집니다. 살바도르편을 시작하려고 새 게임을 만들 필요는 없습니다.

## 본편과 다른 점

| 항목 | 외전에서의 이용 방법 |
| --- | --- |
| 저장 | 본편과 따로 저장됩니다. 외전 저장을 골라 이어 하세요. |
| 다른 기기에서 이어하기 | 같은 계정으로 로그인한 뒤 **불러오기 → 외전 저장 → 계정에서 외전 받기**로 진행을 받아 이어 합니다. 웹과 Android 사이에서도 이용할 수 있습니다. |
| 도전과제와 순위표 | 외전 진행은 본편의 캐릭터 도전과제와 순위표에 반영되지 않습니다. |
| 이야기 자동 진행 | 연결 키 없이 켤 수 있습니다. 이동과 대사를 맡기며, 해전·지도 탐색 등 직접 할 일에서는 멈춥니다. |
| 자동 교역 | 본편 전용입니다. 외전에서는 **이야기 자동 진행** 모드를 이용하세요. |
| 음악 | 밀란다편·살바도르편의 항구와 바다에서 전용 음악이 흐릅니다. 설정에서 원작 음악도 고를 수 있습니다. |

## 외전 클라우드 저장

1. 플레이하던 기기에서 계정으로 로그인하고 기존 외전 저장을 불러옵니다.
2. **항해 → 기능 → 저장하기**로 한 번 더 저장합니다. 기존 기기 저장도 이때부터 계정에 올릴 수 있습니다.
3. **설정 → 온라인**에서 연결 상태를 확인하고, 저장을 올리는 동안 게임을 닫지 마세요.
4. 다른 기기의 웹 또는 Android에서 같은 계정으로 로그인합니다.
5. 타이틀의 전체 **불러오기**에서 **계정에서 외전 받기**를 누른 뒤, 원하는 외전 저장을 골라 이어 합니다.

기기와 계정에 서로 다른 외전 진행이 있으면 어느 쪽으로 이어 할지 선택합니다. 받기 전에 표시된 인물·날짜를 비교하세요. 외전을 받아도 본편 저장은 바뀌지 않으며, 이전 기기 저장은 자동 백업으로 남습니다. **다른 저장 보기** 또는 **외전 자동 백업 보기**에서 찾아볼 수 있습니다.

인터넷 연결이 끊겨도 기기에는 저장됩니다. 연결을 복구한 뒤 다시 저장하거나 **다시 연결**을 누르세요. 계정에 올리지 않은 진행은 브라우저 데이터 삭제나 앱 삭제 시 잃을 수 있습니다. 두 기기에서 동시에 진행하기보다는, 한 기기의 저장을 마친 뒤 다른 기기에서 받아 이어 하세요.

## 공략 읽는 순서

- [밀란다편](/side-story/milanda/): 도입, 첫 배 마련, 교수의 탐험 의뢰와 작위.
- [살바도르편](/side-story/salvador/): 장 전환, 해전 준비와 마지막 이야기.
- [목표 확인과 막힌 곳 해결](/side-story/help/): 의뢰 지도, 바다에서 기다리기, 결투와 자동 진행.
- [조선 외전: 검은 학을 쫓아](/side-story/joseon/): 조선 수군 무관 윤해강의 두 번째 외전.
- [카리브 외전: 수배서의 주인](/side-story/bounty/): 현상금 사냥꾼으로 자라는 소년 마테오의 세 번째 외전 (배포 준비 중).

공략에는 이야기의 흐름과 결말에 관한 내용이 포함되어 있습니다. 다음 목적지만 알고 싶다면 게임 화면 왼쪽 위 **외전 · 현재 목표**부터 확인하세요.
