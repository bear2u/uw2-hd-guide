다음에 할 일을 놓쳤다면 화면 왼쪽 위 **외전 · 현재 목표**를 확인하세요. **정보 → 임무 수첩**에는 진행 정도도 나옵니다. 같은 건물에 계속 들어가기보다 목표가 바뀌었는지 먼저 살펴보세요.

## 목표에 따라 행동하기

| 목표 또는 상황 | 할 일 |
| --- | --- |
| 특정 항구의 건물에 가라는 안내 | 그 항구에 입항하고 지정한 건물에 들어갑니다. |
| 건물이 닫혀 있음 | 여관에서 시간을 보낸 뒤 다시 방문합니다. |
| 바다에서 며칠째를 맞으라는 안내 | 출항해 요구한 날까지 항해합니다. 마을에서 숙박하는 것과는 다릅니다. |
| 특정 함대와 싸우라는 안내 | 바다에서 해당 함대를 찾아 해전을 치릅니다. |
| 의뢰 지도 탐색 안내 | 물품에서 지도를 사용하고 X 가까이에 상륙해 탐색합니다. |
| 작위가 필요하다는 안내 | 명성을 쌓고 왕실 임무를 해결한 뒤 항구 관리소에 들릅니다. |
| 마지막 해전은 끝났지만 완결 안내가 없음 | 바다에서 이어지는 대화와 제작진 크레딧을 확인합니다. |

## 지도에서 X를 찾았는데 발견하지 못해요

지도는 **물품 → 지도 선택 → 사용**으로 다시 볼 수 있습니다. 배가 X에서 너무 멀리 떨어져 있지 않은지, 상륙 방향을 제대로 골랐는지 확인하세요. 방향 목록의 **땅·사막·부락·빈 부락·항구·상륙 불가** 표시도 함께 보세요.

강가에 있는 X는 강을 거슬러 올라가 가까운 땅에 내려야 합니다. 발견 후에는 소지품의 지도가 찾은 물건으로 바뀌었는지 확인하고, 현재 목표에 적힌 곳으로 돌아가 보고하세요.

## 자동 항해 중 배가 멈췄어요

**항구 이동**은 알려진 항구와 그려진 해도를 이용합니다. 암본·자카르타 등 동인도 일부 항구와 베르겐에서 출발할 때는 여전히 멈출 수 있습니다. 자동 항해를 해제하고 수동으로 이동한 뒤 다시 목적지를 선택하세요. 이 구간에서 무인으로 도착할 것을 기대하지 마세요.

## 이야기 자동 진행 쓰기

**설정 → AI 에이전트 → 모드 → 이야기 자동 진행**을 고르고 켭니다. 외전에서도 연결 키 없이 사용할 수 있고, 새 게임에서 배를 얻기 전에도 켤 수 있습니다.

- 다음 건물로 걷기, 항구 사이 이동, 대사 넘기기를 맡깁니다.
- **대화 넘김 속도**에서 읽기 편한 속도를 고릅니다.
- 해전·의뢰 지도 탐색·모험 및 해적 명성·작위·동맹항·정해진 바다 지점으로 가는 일은 직접 해야 합니다.
- 멈추면 오른쪽 진행 창을 펼쳐 이유를 읽고 **직접 조작**으로 필요한 일을 마친 뒤 다시 켭니다.

게임 화면을 열어 두어야 합니다. 앱을 닫거나 웹 페이지를 벗어나도 이야기가 계속 진행되는 기능은 아닙니다. 자세한 설정은 [AI 에이전트 안내](/ai/agent/)에서 확인하세요.

## 외전 저장이 보이지 않아요

타이틀의 **불러오기**에서 해당 외전을 먼저 고르세요. 밀란다와 살바도르는 **외전 1 · 밀란다 / 살바도르**에 함께 보관됩니다. 같은 계정인지 확인하고, 다른 기기의 진행은 **계정 저장 보기**에서 받습니다.

이전 버전의 저장은 **이전 버전의 외전 계정 저장 보기**에서 확인하세요. 빈칸이 부족해 옮기지 못한 내용은 **보존한 원본 보기**에 남습니다. 기기와 계정의 진행이 다르면 인물·날짜를 비교해 선택하세요. 자세한 순서는 [외전 클라우드 저장](/side-story/#외전-클라우드-저장)과 [저장 안내](/start/account-save/)를 참고하세요.
