AI 부관을 이용하려면 인터넷 연결과 본인 계정에서 발급받은 개인 연결 키가 필요합니다. **Claude**(Anthropic), **DeepSeek**, **OpenAI** 중 하나를 골라 연결할 수 있으며, 이용 요금은 고른 서비스의 본인 계정에 부과됩니다.

## 처음 연결하기

1. 게임의 **설정 → AI 도우미 설정**을 엽니다.
2. **연결할 AI**에서 **Claude**, **DeepSeek**, **OpenAI** 중 하나를 고릅니다. 처음에는 Claude가 골라져 있습니다.
3. Claude를 골랐다면 **모델**과 **노력**을 고릅니다. 처음에는 **Haiku 5.5**, 노력 **보통**입니다.
4. **개인 API 키** 입력란에 고른 서비스의 연결 키를 붙여 넣고 **키 적용**을 누릅니다.
5. 게임으로 돌아가 **AI 부관**에게 질문을 보냅니다.

## Claude 모델과 노력

| 선택 | 특징 |
| --- | --- |
| Haiku 5.5 | 가장 빠르고 요금이 낮습니다. 평소 질문과 자동 교역 계획에 알맞습니다. |
| Sonnet 5.5 | 더 꼼꼼하게 답합니다. 요금은 Haiku보다 높습니다. |
| Opus 5.5 | 가장 깊이 생각합니다. 답이 느리고 요금이 가장 높습니다. |

**노력**(낮음·보통·높음·매우 높음·최대)은 답하기 전에 얼마나 깊게 생각할지 정합니다. 높일수록 답이 느려지고 요금이 늘어납니다. 보통으로 시작해 보고, 답이 아쉬울 때 올려 보세요.

연결 키는 서비스마다 따로 보관됩니다. 연결할 AI를 바꾸면 그 서비스의 키를 다시 적용하세요. 고른 AI·모델·노력은 다음에 게임을 열어도 그대로 남지만, 키는 남지 않습니다.

키 적용 안내는 입력한 키를 보관했다는 뜻입니다. 실제 연결 가능 여부는 질문을 보낼 때 확인됩니다.

## OpenAI 연결



**설정 → AI 도우미 설정 → OpenAI**에서 본인의 OpenAI 연결 키를 입력하고 **키 적용**을 누르세요. **GPT-6 Luna**를 사용하며, AI 부관 상담과 AI 에이전트 자동 교역 계획에 함께 적용됩니다. Claude의 모델·노력 선택은 OpenAI에 적용되지 않습니다.

- 연결을 확인하려면 **AI 부관**에서 “지금 함대와 보급 상태를 알려줘”라고 물어보세요. 답변의 수치를 함대 화면과 비교할 수 있습니다.
- 자동 교역은 [AI 에이전트 안내](/ai/agent/)에 따라 시작하세요. 진행 창에서 선택한 계획과 매입·출항·판매 상황을 확인하고, **직접 조작**으로 멈출 수 있습니다.
- 질문과 필요한 게임 정보는 OpenAI로 전달되며, 사용량은 본인의 OpenAI 계정에 과금됩니다.
- 다른 서비스의 연결 키와 따로 보관하며, 게임을 닫으면 지워집니다.
- **이야기 자동 진행**은 연결 키 없이 그대로 이용할 수 있습니다.

## 키와 대화 정보

- 키는 게임 실행 중에만 보관됩니다. 게임을 닫거나 웹 페이지를 새로 고친 뒤에는 다시 입력하세요.
- **키 지우기**를 누르면 현재 연결 키를 지웁니다. 이미 보관된 대화 기록은 남습니다.
- 질문과 답변에 필요한 게임 정보, 이어지는 대화 내용은 고른 서비스(Anthropic, DeepSeek 또는 OpenAI)로 전달됩니다.
- 키를 다른 사람에게 전달하거나 공개 게시글·화면 사진에 넣지 마세요. 대화에도 비밀번호나 결제 정보를 적지 마세요.

## 연결되지 않을 때

인터넷 연결을 확인하고, 키 앞뒤에 공백이나 줄바꿈이 들어갔는지 살펴보세요. 게임을 다시 열었다면 키를 다시 적용해야 합니다. 연결할 AI와 붙여 넣은 키의 서비스가 같은지 확인하세요. 계속 연결되지 않으면 그 서비스 계정의 이용 가능 상태와 잔액을 확인하고 잠시 뒤 다시 시도하세요. Opus나 높은 노력은 답이 오기까지 시간이 더 걸립니다.

응답을 받지 못했다면 질문을 짧게 나눠 다시 물어보세요. 연결이 되지 않아도 상담창을 닫고 게임을 계속할 수 있습니다.
