AI 부관을 이용하려면 인터넷 연결과 본인의 DeepSeek 계정에서 발급받은 개인 연결 키가 필요합니다. DeepSeek 이용 요금은 본인의 계정에 부과됩니다.

## 처음 연결하기

1. 게임의 **설정 → AI 도우미 설정**을 엽니다.
2. **개인 API 키** 입력란에 본인의 DeepSeek 연결 키를 붙여 넣습니다.
3. **키 적용**을 누릅니다.
4. 게임으로 돌아가 **AI 부관**에게 질문을 보냅니다.

키 적용 안내는 입력한 키를 보관했다는 뜻입니다. 실제 연결 가능 여부는 질문을 보낼 때 확인됩니다.

## 키와 대화 정보

- 키는 게임 실행 중에만 보관됩니다. 게임을 닫거나 웹 페이지를 새로 고친 뒤에는 다시 입력하세요.
- **키 지우기**를 누르면 현재 연결 키를 지웁니다. 이미 보관된 대화 기록은 남습니다.
- 질문과 답변에 필요한 게임 정보, 이어지는 대화 내용은 DeepSeek로 전달됩니다.
- 키를 다른 사람에게 전달하거나 공개 게시글·화면 사진에 넣지 마세요. 대화에도 비밀번호나 결제 정보를 적지 마세요.

## 연결되지 않을 때

인터넷 연결을 확인하고, 키 앞뒤에 공백이나 줄바꿈이 들어갔는지 살펴보세요. 게임을 다시 열었다면 키를 다시 적용해야 합니다. 계속 연결되지 않으면 DeepSeek 계정의 이용 가능 상태와 잔액을 확인하고 잠시 뒤 다시 시도하세요.

응답을 받지 못했다면 질문을 짧게 나눠 다시 물어보세요. 연결이 되지 않아도 상담창을 닫고 게임을 계속할 수 있습니다.
