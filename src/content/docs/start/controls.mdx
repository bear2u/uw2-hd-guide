## 마을

방향키 또는 WASD로 걷습니다. 화면 방향 단추와 마우스·터치도 사용할 수 있습니다. 항구 지도나 건물 목록에서 이름을 선택하면 해당 문까지 자동으로 걷습니다. 건물에 도착해도 영업 시간이 아니면 잠긴 문 안내가 나옵니다.

**정보 → 항구 정보**로 [현재 항구의 발전도와 투자액](/systems/investment/)을, **항해 → 물품**으로 [소지품 확인·사용·장비 변경](/atlas/items/)을 할 수 있습니다.

## 항해

화면의 입항·상륙·함대 단추는 현재 상황에 맞춰 나타납니다. 세계 지도에서 위치와 항로를 확인하고, 바다에서는 휠·핀치로 확대를 조절할 수 있습니다. 경영 단추 또는 F2로 선원·선장·적재를 관리합니다. 정지와 상륙 대기는 보급·시간 규칙의 영향을 받으므로 안전한 일시정지와 구분하세요.

## 대화와 메뉴

대화의 선택지를 읽고 확인합니다. Esc는 뒤로 가기, M은 메뉴 숨기기에 사용합니다. 숫자 입력과 확인창은 선택한 상품·배·수량을 다시 읽은 뒤 확정하세요. 저장 불러오기를 취소하면 현재 게임을 이어갑니다.

## 해전

**선택한 배와 현재 행동 차례인 배는 다를 수 있습니다.** 차례 표시와 배 카드의 선원·내구를 함께 봅니다. 이동 가능한 칸, 포격 거리, 포탄, 측면 방향이 공격 가능 여부를 결정합니다. 상대를 선택해도 조건이 맞지 않으면 포격할 수 없습니다.

기함 이름표와 작은 지도의 깃발로 기함을 구분하고, 끌기로 화면 이동, 휠·**+ / −**로 확대·축소, **화면 맞춤**으로 보기 복원을 할 수 있습니다. 칸이나 공격 대상을 선택할 때는 큰 안내가 자동으로 숨겨집니다. 자세한 조작은 [해전 화면 안내](/systems/battle/)를 참고하세요.

## 빠르게 진행하기

해상·해전의 1배·2배·4배 속도는 대기 시간을 줄입니다. 물자와 날짜를 없애는 기능은 아닙니다. 가까운 적이나 보급이 부족한 항차는 속도를 낮춰 대응하세요. 화면 설정을 여는 동안은 게임 시간이 정지됩니다.

## 게임패드

**설정 → 게임패드 설정**에서 패드 사용 여부, 버튼 배치, 스틱 유격과 포인터 속도를 조절합니다.

| 기본 조작 | 기능 |
|---|---|
| 왼쪽 스틱 | 마을 걷기·항해 침로 변경 |
| 방향키 | 메뉴 항목 선택 |
| 오른쪽 스틱 | 포인터 이동 |
| A / × | 선택·확인, 누른 채 포인터를 움직이면 끌기 |
| B / ○ | 뒤로 가기 |
| 메뉴 / Options | 게임 메뉴 표시·숨김 |
| Y / △ | 설정 열기·닫기 |
| LB / RB | 이전·다음 메뉴 항목 |
| LT / RT | 스크롤·바다 확대 조절 |

패드 사용 중에는 터치 조이스틱을 숨깁니다. 연결이 끊어지거나 패드 사용을 끄면 기존 터치 조작과 표시 설정으로 돌아갑니다. 원래 숨겨 둔 조이스틱은 계속 숨겨집니다.

웹에서는 기기에 패드를 연결하고 게임 화면을 터치한 뒤 패드 버튼을 눌러 주세요. 기기·브라우저가 패드를 인식해야 사용할 수 있습니다. 글자 입력은 화면 키보드나 키보드를 사용하세요.
