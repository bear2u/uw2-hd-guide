본편과 외전의 진행을 캐릭터별로 보관합니다. 이전 버전의 저장도 원본을 남기고 가져올 수 있습니다.

## 캐릭터별 아홉 저장 공간

계정마다 본편 여섯 주인공과 외전 세 편의 저장 공간을 따로 사용합니다. **밀란다와 살바도르는 이어지는 이야기이므로 외전 1 저장 공간을 함께 사용**합니다.

각 저장 공간에는 **수동 저장 9칸과 자동 저장 1칸**이 있습니다. 다른 캐릭터를 시작하거나 저장해도 이전 캐릭터의 진행은 유지됩니다.

## 저장하고 이어하기

1. 게임의 **저장하기**에서 수동 슬롯을 고르고 내용을 확인합니다. 이미 사용 중인 칸은 덮어쓰기 전에 확인하세요.
2. 입항 등의 자동 저장은 해당 캐릭터의 **자동 저장** 칸에 기록됩니다. 해전이나 장거리 항해 전에는 수동 저장도 남겨 두세요.
3. 처음 화면에서 **불러오기 → 캐릭터 또는 외전 → 저장 목록**으로 들어갑니다.
4. 저장을 선택하면 얼굴·이름·날짜·위치·금화·이야기 진행을 볼 수 있습니다. 내용을 확인하고 **이어하기**를 누르세요.

## 같은 캐릭터를 새로 시작할 때

기존 수동 저장은 그대로 남습니다. 이전 자동 저장이 있으면 먼저 빈 수동 칸에 보관한 뒤 새 진행을 시작합니다. 다른 시점의 저장을 불러올 때도 기존 자동 저장을 보호합니다.

수동 9칸이 모두 찼다면 기존 자동 저장을 보관할 칸을 고르고 **덮어쓰기 확인**을 눌러야 합니다. 취소하면 새 진행을 시작하지 않습니다. 선택한 칸의 이전 내용은 **보존한 원본 보기**에서도 확인할 수 있습니다.

## 이전 버전의 저장

기존 저장은 지우지 않고 캐릭터별로 복사합니다. 같은 캐릭터로 저장한 여러 슬롯도 함께 보존합니다. 이전 도중 앱이 닫혔다면 다시 실행해 불러오기 목록을 확인하세요.

빈칸이 부족해 목록에 들어가지 못한 진행은 **불러오기 → 해당 캐릭터 → 보존한 원본 보기**에서 선택할 수 있습니다. 원본을 불러올 때도 현재 저장 목록을 통째로 교체하지 않습니다.

## 손님과 계정

손님으로도 플레이할 수 있으며, 연결하지 못한 동안에는 이 기기에 저장합니다. 처음 계정에 연결할 때 손님 진행은 원본을 남기고 계정 저장 공간으로 복사합니다. 다른 계정으로 바꾸면 해당 계정의 저장 목록을 사용합니다.

브라우저 저장은 사이트와 브라우저별로 다릅니다. 다른 기기에서 이어 하려면 같은 계정으로 로그인하세요. 앱 데이터나 브라우저 저장 공간을 지우면 기기에만 있는 진행과 보존한 원본도 지워질 수 있습니다.

## 클라우드에서 이어하기

**불러오기 → 캐릭터 → 계정 저장 보기**에서 내용을 확인하고 이어하기를 선택합니다. 기기와 계정에 서로 다른 진행이 있으면 자동으로 하나를 덮어쓰지 않습니다. 가져온 원본을 보존하고 빈칸에 복사하며, 자리가 부족하면 사용할 칸을 직접 선택합니다.

이 기기 진행을 계속 계정에 저장하려면 **이 기기 진행을 계정에 사용… → 확인**을 누릅니다. 계정의 기존 내용은 원본으로 보존하며, 이후 게임에서 저장할 때 선택한 진행을 올립니다. 다른 기기에서 그사이 저장했다면 다시 선택해야 할 수 있습니다.

이전 버전의 계정 저장은 전체 불러오기 화면의 **이전 버전의 계정 저장 보기**, 외전은 해당 저장 공간의 **이전 버전의 외전 계정 저장 보기**에서 가져옵니다. 기존 계정 저장은 그대로 남습니다. **계정의 보존한 원본 가져오기**로 이전 선택 당시의 진행도 확인할 수 있습니다.

연결 실패가 저장 삭제를 뜻하지는 않습니다. 기기의 진행을 확인하고 다시 연결하세요. 계정 저장 중에는 앱이나 탭을 닫지 마세요.

## 도전과제·카드와 게임 저장

도전과제와 카드 수집·친밀도는 게임 슬롯과 별도 기록입니다. 과거 저장을 불러오거나 같은 캐릭터를 새로 시작해도 이미 받은 보상을 다시 지급하지 않으며, 달성한 기록을 초기화하지 않습니다. 돈·함대·물품·이야기 상태는 선택한 게임 저장 시점으로 돌아갑니다.

지도 메모는 기기에 보관하는 개인 기록이며 클라우드 게임 저장에 포함되지 않습니다. 도전과제만 다르게 보인다면 같은 계정인지 확인하고 [도전과제 안내](/challenges/overview/)를 참고하세요.
