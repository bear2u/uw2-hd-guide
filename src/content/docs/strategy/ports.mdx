## 원작 참고: 지역별 지도

샤르티에의 항구 일람은 지중해·북유럽·아프리카·중동·아시아·아메리카 등으로 나눠 항구와 보급항, 주요 시설과 상품을 안내합니다. 지중해와 북유럽에서는 교역·조선·도구 구입 거점을, 먼 해역에서는 보급 거점을 함께 찾는 데 유용합니다. 지역별 원작 지도 그림은 [세계지도와 항구일람 원문](https://s0252.tistory.com/5?category=587904)에서 확인할 수 있습니다.

## 지역별로 원작 지도를 펼칠 때

| 지역 | 원작 지도에서 함께 살펴볼 것 |
|---|---|
| 지중해 | 수도와 교역·도구 구입 거점 |
| 북유럽 | 조선과 항해 도구 준비 거점 |
| 서북 아프리카 | 마데이라와 내륙 접근 |
| 남부·동부 아프리카 | 희망봉을 도는 항차와 중간 보급 |
| 중동·인도 | 이야기 방문지와 다음 원정 거점 |
| 동남아시아 | 섬 사이의 항구와 보급항 |
| 호주·뉴질랜드 | 보급항과 탐험 동선 |
| 동아시아 | 이야기 조건이 있는 항구와 조선 |
| 중앙아메리카·카리브해 | 대서양·태평양 쪽 해안 구분 |
| 남아메리카 | 긴 남하 항차와 귀항 거점 |

위 구분은 원작 지도를 찾아 읽기 위한 안내입니다. 현재 항구의 시설·판매 목록·방문 조건은 HD 게임에서 확인합니다. [지역별 원작 지도](https://s0252.tistory.com/5?category=587904)

## 여행 목적에 맞는 거점 고르기

| 상황 | 먼저 찾을 거점 | 도착 후 할 일 |
|---|---|---|
| 첫 돈벌이 | 이미 알고 있는 가까운 일반 항구 | 교역 도우미와 실제 판매 견적 비교 |
| 새 배 준비 | 원하는 모델을 취급하는 조선소 | 공업·건조 조건과 인수 시점 확인 |
| 장거리 원정 | 항로 중간의 항구·보급항 | 남은 보급과 다음 기항까지의 거리 점검 |
| 이야기 진행 | 현재 장에서 지정한 항구 | 해당 시설·인물을 직접 방문 |
| 동맹항 확대 | 투자할 수 있는 대상 항구 | 지지율과 소속 확인 |

보급항을 일반 항구처럼 생각해 모든 수리·고용·교역을 해결할 계획을 세우지 마세요. 필요한 시설이 있는 일반 항구도 귀항 후보로 남깁니다.

## 항구를 못 찾을 때

1. [항구 도감](/atlas/ports/)에서 이름과 좌표를 확인합니다. 원작 글과 한글 표기가 다를 수 있습니다.
2. 이야기 조건으로 숨겨진 항구인지 [캐릭터 공략](/strategy/stories/)을 확인합니다.
3. 목적지가 같은 해안에 있는지 확인하고, 돌아갈 길을 포함해 보급을 준비합니다.

원작 글의 투자 가능 항구 수나 국가 구분을 현재 항해의 완료 조건으로 대신하지 마세요. 이야기에서 요구하는 조건과 실제 항구 정보를 우선합니다.
