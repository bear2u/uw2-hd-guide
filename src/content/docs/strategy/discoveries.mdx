## 원작 참고: 지역별 발견물 지도

샤르티에의 발견물 일람은 98종의 후보를 지역별로 소개하고, 한 게임에서 전부 찾는 방식이 아니라고 설명합니다. 초반 나일강 유역부터 아프리카·아시아·오세아니아·아메리카·극지방까지 지도로 정리돼 있습니다. 검치호·맘모스처럼 먼 지역의 대상을 찾을 때도 원문 그림과 함께, 현장에서 이번 게임에 있는 부락인지 확인하세요. [세계 지도와 발견물 일람 원문](https://s0252.tistory.com/46?category=587904)

## 탐색 한 번의 순서

1. **대상 고르기:** 도감에서 가까운 후보를 여러 곳 정해 둡니다. 이번 게임에 없는 곳일 수도 있습니다.
2. **왕복 준비:** 상륙·탐색에 쓸 식량과 선원, 귀항 보급을 따로 남깁니다.
3. **접근:** 좌표와 인접한 접근 가능한 해안을 찾습니다. 배로 육지의 좌표까지 들어가는 것이 아닙니다.
4. **상륙·환대·탐색:** 상륙할 방향 목록에서 **부락**이라고 표시된 곳을 고릅니다. 현장의 선택과 결과를 확인합니다. 탐색 실패와 선원 손실이 생길 수 있습니다.
5. **발견 확인:** 발견 기록과 실제 선원·식량 변화를 살핍니다.
6. **보고:** 수집가에게 돌아가 보고와 보상을 확인합니다.

## 아무것도 발견되지 않을 때

| 확인 사항 | 다음 행동 |
|---|---|
| 상륙 목록에 **빈 부락**으로 나오는가? | 이번 게임에 쓰지 않는 부락입니다. 환대·약탈·보물탐색이 없고 땅처럼 물만 찾을 수 있으니 다른 부락으로 이동 |
| 이미 발견했는가? | 발견 기록 확인 후 다른 대상 선택 |
| 실제 상륙 가능한 해안인가? | 가까운 접근 지점에서 다시 확인 |
| 식량과 선원이 충분한가? | 항구에서 보급·고용 후 재도전 |
| 이번 탐색만 실패했는가? | 손실과 귀항 여유를 보고 재시도 여부 판단 |

특정 환대 수치가 모든 발견물의 성공을 보장한다고 생각하지 마세요. 멀리 온 만큼 계속 시도하기보다 돌아갈 인원과 식량이 남는지를 먼저 봅니다.
