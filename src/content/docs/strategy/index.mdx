## 초보 선장의 진행 순서

1. 출발 전에 저장하고 귀항용 보급비를 남깁니다.
2. 가까운 두 항구에서 소량을 거래하며 실제 수익을 확인합니다.
3. 유지비를 감당할 수 있을 때 배와 동료를 늘립니다.
4. 탐험·교역·전투 중 주인공의 이야기 조건에 맞는 활동을 합니다.
5. 조건을 채웠다면 해당 인물을 다시 만나 이야기 진행을 확인합니다.

## 원작 공략과 함께 읽는 법

각 페이지의 **원작 참고**는 외부 공략의 핵심을 짧게 정리한 내용입니다. **HD 플레이 안내**는 이 항해 수첩의 현재 게임 안내와 연결됩니다. 원작 지도에 표시돼 있어도 현재 주인공에게 활성화되지 않은 발견물이나 이야기 조건이 필요한 항구가 있을 수 있습니다.

그림은 항해 수첩의 좌표 자료로 새로 그린 분포도입니다. 원문 지도와 스크린샷은 [참고 공략 모음](/strategy/references/)에서 볼 수 있습니다.
