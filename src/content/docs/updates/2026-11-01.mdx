**모바일 및 웹 배포 완료.**

## 캐릭터별 저장과 기존 진행 보호

- 본편 6명과 외전 3편을 **아홉 저장 공간**으로 나눕니다. 밀란다·살바도르는 하나의 저장 공간을 함께 사용합니다.
- 각 저장 공간에 **수동 저장 9칸과 자동 저장 1칸**을 제공합니다. **불러오기 → 캐릭터 또는 외전**에서 저장 목록과 진행 내용을 확인하세요.
- 다른 캐릭터를 시작해도 이전 진행을 유지합니다. 같은 캐릭터를 새로 시작할 때도 이전 자동 저장을 보관하며, 빈칸이 없으면 사용할 수동 칸을 직접 선택합니다.
- 이전 버전 저장은 원본을 남기고 복사합니다. 빈칸이 부족해 옮기지 못한 진행은 **보존한 원본 보기**에서 확인할 수 있습니다.
- 기기와 계정에 서로 다른 진행이 있으면 사용할 내용을 직접 선택합니다. 도전과제·보유 카드·친밀도는 게임 슬롯과 별도로 유지됩니다.
- 자세한 사용법은 [계정, 저장과 불러오기](/start/account-save/)에서 확인하세요.

## 범선과 선원이 함께하는 기본 카드 덱

- 불·숲·물 덱을 **전투·해적 / 탐험·보급 / 항해·교역** 덱으로 바꿨습니다. 선원, 범선, 항구, 해도와 보급품을 담은 새 그림과 이름을 사용합니다.
- 마나는 **지휘력**, 주문은 **전술**, 영웅은 **선장**으로 표시합니다. 보유 카드와 덱 구성, 카드 능력·비용, 직접 지은 덱 이름은 유지됩니다.
- 카드 대전으로 넘어가거나 컴퓨터 상대가 행동할 때 진행이 멈추던 현상을 보완하고, 컬렉션의 덱 제목 표시를 정리했습니다.
- 메뉴·대전·팩 개봉에 배경음과 효과음을 더했습니다.

## 해도 탁자와 항해일지로 꾸민 카드 대전

**모바일 및 웹 배포 완료.**

- 카드 선택 화면과 대전판을 목재 탁자·해도·황동 장식으로 꾸밉니다.
- 기본 카드 뒷면과 쌓인 덱에 범선과 나침반 문양을 넣습니다.
- 전투 기록과 설명 창은 어두운 항해일지 바탕으로 바꾸어 카드와 글씨가 눈에 잘 들어오도록 합니다.
- [카드게임 시작하기](/card-game/)에 새 메뉴 화면를, [첫 대전 따라하기](/card-game/tutorial/#전투-기록-확인하기)에 대전판·카드 뒷면·전투 기록 설명을 그림과 함께 추가했습니다. 항해 훈련의 단계 선택 화면도 함께 안내합니다.

## 항해 훈련 · 단계별 카드게임 튜토리얼

**모바일 및 웹 배포 완료.**

- 카드 대전 메뉴의 **모험**이 **항해 훈련**으로 바뀝니다. 다섯 단계를 차례로 하며 카드게임 규칙을 익힙니다.
- 단계마다 항해일지 모양의 안내 상자가 다음 행동을 알려 줍니다. 1단계 「첫 출항」은 카드 내기·공격·턴 종료를, 2~5단계는 보급과 회복, 수비와 돌파, 선원 운용, 대형 함선을 다룹니다.
- 안내 문구와 단계 이름을 지금의 카드 이름과 용어(지휘력·전술·선장)에 맞췄습니다.
- 훈련 안내가 떠 있는 동안 카드 확대창이 안내 문구를 가리지 않도록 했습니다.
- 1단계를 깨기 전까지 항해 훈련 단추에 **처음이라면 여기부터** 표시가 붙습니다.
- 단계 구성은 [첫 대전 따라하기](/card-game/tutorial/#게임-안에서-따라-하기--항해-훈련)에서 확인하세요.

## 카드 설명 바로잡기

**모바일 및 웹 배포 완료.**

- 카탈리나의 고유 전술이 설명대로 모든 아군 유닛에게 **공격력과 체력 +2**를 줍니다. 지금까지는 공격력만 올랐습니다. 일반 전술 「돌격 명령」과 구분되도록 이름을 **전 함대 돌격**으로 바꿨습니다.
- **독화살 사수:** 공격받을 때 공격한 유닛에게도 독을 건다는 설명을 더했습니다.
- **추격 함장**과 **취약 지점 공략:** 내 유닛도 대상이 된다는 설명을 더했습니다. 카드 효과 자체는 바뀌지 않았습니다.

## Android 설치 파일 용량 줄이기

**모바일 및 웹 배포 완료.**

- 카드 대전의 카드 그림과 글꼴을 정리해 Android 설치 파일 용량을 줄였습니다.
- 카드 내용, 보유 카드와 덱 구성은 그대로입니다. 휴대폰에서 보기에 맞춰 카드 그림을 압축하므로, 큰 화면에서는 그림이 조금 덜 선명할 수 있습니다.
