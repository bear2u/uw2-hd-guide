## 추가 업데이트 · 2026.10.22.3 게임패드 지원

메인 화면의 **설정 → 게임패드 설정**에서 연결 상태를 확인하고 버튼 배치, 스틱 유격과 포인터 속도를 조절할 수 있습니다.

- 패드를 연결하고 사용을 켜면 왼쪽 아래 터치 조이스틱과 게임 메뉴를 숨깁니다.
- 기본 **메뉴 / Options** 버튼으로 게임 메뉴를 표시하거나 숨깁니다. 메뉴를 열어도 터치 조이스틱은 나타나지 않습니다.
- 왼쪽 스틱으로 걷거나 침로를 바꾸고, 방향키로 메뉴를 선택합니다. 오른쪽 스틱으로 포인터를 움직여 세밀한 항목을 선택하거나 끌 수 있습니다.
- 기본 **Y / △** 버튼으로 설정을 열 수 있습니다. 버튼 배치는 현재 기기에 저장됩니다.
- 패드 연결을 해제하거나 사용을 끄면 기존 터치 조작과 메뉴 표시 설정으로 돌아갑니다.

웹에서는 패드를 먼저 기기에 연결하고 게임 화면을 한 번 터치한 뒤 패드 버튼을 눌러 주세요. 기기와 브라우저가 인식하는 패드에 따라 이용 범위가 다를 수 있습니다. 아이디·비밀번호 등 글자는 화면 키보드나 키보드로 입력합니다.

모바일 및 웹 배포 완료.

## 앞선 웹 버전 업데이트

2026년 10월 22일 웹 버전 **2026.10.22-sea-guide**에 아래 내용을 적용했습니다. [웹에서 플레이하기](https://sujifather.itch.io/uw2-hd)에서 접속할 수 있으며 비밀번호는 **12345678**입니다. 이미 게임을 열어 두었다면 진행 내용을 저장한 뒤 페이지를 새로고침하세요.

같은 날짜에 Android APK도 별도로 배포했습니다. 아래 Android 안내에서 버전과 설치 대상을 확인하세요.

- 캐릭터별 도전과제: 주인공마다 24개씩, 총 144개 과제와 계정별 진행 기록을 제공합니다.
- 교역소 흥정: 교섭·회계 기술을 가진 인물이 가격 협상에 개입하지 않던 문제를 수정했습니다. 해당 기술과 담당 직책 등 조건을 충족하면 할인된 가격으로 구입할 수 있습니다.
- 메인 화면의 가이드 버튼: 로그인 전후에 화면 오른쪽 위에서 항해 수첩을 열 수 있습니다. 웹에서는 새 브라우저 탭으로, 앱에서는 기본 브라우저로 연결됩니다.
- 항해 화면의 바다: 수면을 더 맑은 청록·청색으로 바꾸고, 반복 격자와 거친 물결 겹침을 줄였습니다. 해안선과 항구는 유지하며 밤·안개·폭풍의 분위기도 구분됩니다.
