원작의 배 25종을 그림과 함께 정리했습니다. 값은 **본편 새 게임 시작 기준**이며 여섯 주인공 모두 같습니다. 실제 배는 재질·개조·손상에 따라 달라지므로 조선소와 함대 정보 화면의 값을 우선하세요.

배 이름을 누르면 [종류별 상세](/ships/details/)로 이동합니다. 목적에 맞는 배를 찾으려면 [용도별로 고르기](/ships/choose/)를, 어느 항구에서 지을 수 있는지는 [조선소별 건조 목록](/ships/shipyards/)을 보세요.

**새 함선:** 이야기를 끝낸 뒤 자유 항해에서는 지역 조선소가 새 배 44종을 짓고, 숨은 조선소가 6종을 더 팝니다. 이 페이지의 원작 배 25종과 따로 [새 함선](/ships/new/)에 정리했습니다.

## 숫자를 읽는 법

| 항목 | 뜻 |
|---|---|
| 구분 | **범선**과 **노 젓는 배**입니다. 노 젓는 배는 바람이 약하거나 없어도 노로 나아갑니다. 함대에 노 젓는 배가 한 척도 없으면 무풍에서 멈출 수 있습니다. |
| 적재량 | 배 안의 전체 공간입니다. 선실(선원)·대포 칸·짐칸이 이 공간을 나눠 씁니다. 조선소에서 선실과 대포 칸을 정하면 나머지가 짐칸이 됩니다. |
| 최소 선원 | 배를 움직이는 데 필요한 인원의 기준입니다. 최고 속력에 필요한 실제 인원은 항해 담당 비율에 따라 달라집니다. [선원 수와 속력](/systems/fleet/#선원-수와-속력)을 참고하세요. |
| 최대 선원 | 태울 수 있는 선원의 상한입니다. |
| 내구 | 새 배 최대 내구의 기준입니다. 새 배의 실제 최대 내구는 재질에 따라 달라지며 100을 넘지 않습니다. |
| 추진·선회 | 속력 계산에 들어가는 배의 성능값입니다. 실제 속력은 바람·선원·짐·선장의 능력이 함께 정합니다. [항해와 보급](/systems/navigation/)을 참고하세요. |
| 포문 | 실을 수 있는 대포 수의 상한입니다. |
| 기준 가격 | 모델의 기준값입니다. 새 배의 실제 가격은 재질과 항구 시세에 따라 달라집니다. |
| 필요 공업 | 조선소가 있는 항구의 공업이 이 값 이상이어야 건조 목록에 나옵니다. |
